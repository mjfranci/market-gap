## Usage Instructions

At the start of each market research session (Stage 02), load this file and ask:

> "I have a list of consulting firm insight sources (McKinsey, BCG, Bain, Deloitte, PwC, KPMG, EY, Accenture, Roland Berger, Capgemini). Would you like me to draw from these during research?"

If yes, use the URLs above as starting points when searching for industry reports, trends, and data relevant to the target market.
